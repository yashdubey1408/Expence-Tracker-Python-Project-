# Expence-Tracker-Python-Project-

A command-line Expense Tracker built in Python that lets users add expenses, view all recorded entries, and calculate total spending using lists, dictionaries, and loops.

## Features
- **Add Expense:** Record date, category, description, and amount with input validation.
- **View All Expenses:** Display all added expenses in a numbered list.
- **View Total Spending:** Calculate and show total expenditure.
- **Exit:** Safely close the program.
